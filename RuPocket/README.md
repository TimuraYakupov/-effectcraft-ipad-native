# RuPocket — прототип клиента RuTracker для iPhone

Версия 0.1.0. iPhone, iOS 17 и новее. SwiftUI + WebKit. Приложение работает с сайтом напрямую; отдельный сервер не нужен.

## Что реализовано в исходниках

- Встроенный браузер с сохранением сессии RuTracker и входом через форму самого сайта.
- Адаптация страниц под телефон: размеры текста, поля, карточки результатов поиска, изображения и описания.
- Поиск с русским текстом через оригинальную форму сайта; сортировка по сидам, дате, размеру и названию.
- Избранное, переходы назад/вперёд, открытие страницы в Safari.
- Скачивание `.torrent` с текущей сессией WebKit, проверка bencode и хранение на устройстве.
- Системное меню «Поделиться», сохранение в «Файлы», копирование и передача magnet.
- Переключатель исходного вида сайта; удаление данных входа.

Приложение сохраняет **метаданные `.torrent`**. Содержимое раздач оно не загружает.

## Статус проверки

Неподписанный IPA успешно собран в GitHub Actions на macOS с Xcode 16.4. Все 15 тестов прошли: 10 DOM-проверок и 5 XCTest на симуляторе iPhone 16 Pro (iOS 18.5). Исходники этой сборки: `c6844251fa1f3dd36ff2f5cdacfcb7b2df2d8b5d`.

Работа с действующим RuTracker, входом в аккаунт, капчей и настоящими раздачами ещё требует проверки на iPhone: сайт недоступен из среды подготовки. Адаптер проверен на синтетических HTML-страницах.

## Скачать и установить IPA

Сборка находится в ветке `rupocket/iphone` репозитория `TimuraYakupov/-effectcraft-ipad-native`. Основная ветка и код EffectCraft не менялись.

1. Открой [успешную сборку](https://github.com/TimuraYakupov/-effectcraft-ipad-native/actions/runs/40338595885).
2. Скачай артефакт **RuPocket-0.1.0-iPhone** и извлеки IPA из ZIP.
3. Импортируй IPA в настроенный Feather или SideStore, подпиши и установи своим сертификатом/Apple ID.

В этом чате также выдан отдельный файл `RuPocket-0.1.0-iPhone.ipa`. Повторно скачивать его из GitHub не обязательно.

Неподписанный IPA напрямую на iPhone не устанавливается. Пароль RuTracker вводится только внутри приложения на странице сайта; добавлять его в репозиторий не нужно.

Workflow `.github/workflows/rupocket.yml` находится в корне репозитория и запускается при новых коммитах ветки `rupocket/iphone`. Сборка EffectCraft в этой ветке ограничена `main`, чтобы не запускаться вместе с RuPocket. Изменения относятся только к отдельной ветке.

## Сборка на Mac

1. Открой `RuPocket.xcodeproj` в Xcode 16 или новее.
2. Выбери target **RuPocket → Signing & Capabilities → Team** со своей учётной записью. При необходимости измени Bundle Identifier.
3. Выбери подключённый iPhone и нажми **Run**.

Для неподписанного IPA:

```bash
bash scripts/build-ipa.sh
```

Результат: `build/RuPocket-0.1.0-unsigned.ipa`.

## Первая проверка на iPhone

1. Проверь, что RuTracker доступен в Safari в используемой сети.
2. Открой RuPocket. Меню `… → Войти в RuTracker`.
3. Найди общедоступную тестовую раздачу с русским названием.
4. Проверь открытие описания, спойлеров, изображений и переходы между страницами результатов.
5. Нажми «Скачать .torrent». Проверь сохранение через «Поделиться → Сохранить в Файлы», затем повторное открытие в разделе «Файлы» приложения.
6. Проверь magnet, избранное, перезапуск приложения и сохранение сессии.
7. Если страница отображается неверно, выключи «Мобильный вид» в меню и пришли адрес страницы и снимок экрана для правки.

## Структура

- `RuPocket/BrowserModel.swift`: WebKit, сессия, поиск, скачивания, избранное.
- `RuPocket/RootView.swift`: интерфейс iPhone и системное меню передачи файлов.
- `RuPocket/Web/mobile.js` и `mobile.css`: адаптация оригинальных страниц; формы сайта сохраняются.
- `RuPocket/TorrentValidator.swift`: ограниченный по размеру и глубине валидатор bencode.
- `RuPocketTests/CoreTests.swift`: XCTest для валидации файлов, имён и адресов.
- `tests/mobile.test.cjs`: проверки адаптера в DOM.
- `scripts/generate_project.py`: воспроизводимая генерация Xcode-проекта без сторонних Python-пакетов.

Проверки адаптера:

```bash
npm ci --prefix tests --ignore-scripts
node tests/mobile.test.cjs
```

RuPocket не связан с администрацией RuTracker. Приложение не содержит собственной аналитики. Загруженные страницы и внешние изображения выполняют сетевые запросы по правилам самого сайта.
